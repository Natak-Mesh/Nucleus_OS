# Example STT grammar phrase list for LoRa voice-text (Vosk).
#
# OPT-IN: point VOICE_STT_GRAMMAR in /etc/nucleus/mesh.conf at a file like
# this one to constrain speech recognition to a fixed radio vocabulary.
# Recognition of listed words/phrases becomes dramatically more accurate;
# anything NOT listed is transcribed as nothing (mapped to [unk]) instead of
# being force-matched to the wrong word — so only enable this if your voice
# traffic really sticks to the vocabulary below.
#
# Format: one lowercase word or phrase per line. Blank lines and '#' comments
# are ignored. [unk] is appended automatically. Edit freely: add your
# callsigns, team names, locations, and unit-specific brevity codes.
#
# To enable:
#   1. cp this file (e.g. to /opt/nucleus/models/vosk/grammar.txt) and edit
#   2. mesh.conf: VOICE_STT_GRAMMAR=/opt/nucleus/models/vosk/grammar.txt
#   3. sudo systemctl restart openvlm-voice
